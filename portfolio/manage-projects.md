# Managing Portfolio Projects

It's pretty simple to manage your projects. It's similar to managing posts. You can go to **Portfolio > All Projects** to manage your projects or go to **Portfolio > Add New** to add a new project.

![Add new portfolio project](_images/portfolio--add-new.png)

In this screen, you will see it is very similar to adding/editing a page.

- **1**: enter project name here
- **2**: enter project content here. You can see we use the default WordPress's gallery to display project images.
- **3**: select project category. You can also add new project categories here.
- **4**: add project tags.
- **5**: upload the feature image for the project.
- **6**: enter the project excerpt (short description). This excerpt is used on project layout v2.
