# Portfolio Page Header

On the portfolio page, you can see the page header on top of projects listing. It contains the page title (such as "Our Projects" or "Hello, I'm ...") and the category filter. You can control them in **Appearance > Customize > Portfolio > Portfolio Page**.

You can disable this page header or select the page header content. By default, the page header content is the portfolio page content. You can choose either:

- Portfolio Page Content: the title of the page which is set as the portfolio.
- Portfolio Page Title: the title of the page which is set as the portfolio.
- Custom Content: with this option, you can manually enter the content for the page header in the Customizer.

> [!NOTE] The portfolio page is set in **Settings > Reading**.
