# Enable Portfolio Support

From the version 1.1.0, Konte start supporting to manage and present your Portfolio. To have this feature, you have to ensure you are using the latest version of **Konte Addons** plugin. If you are using an older version, please see this [update Konte Addons guide](update/update-plugins.md) to update it.


If you are using the version 1.1 or newer of Konte Addons plugin, you can go to **Settings > Writing** to enable Portfolio support.

![Enable portfolio support](_images/portfolio--enable.png)

After you enabled Portfolio support, you can see a new menu "Portfolio" in your admin area. In this menu, you can manage your **Projects** and **Portfolio Categories**.
