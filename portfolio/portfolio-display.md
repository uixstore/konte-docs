# Portfolio Display

Konte has options to help you control how your portfolio be present on the front-end. Please note that your [portfolio page](portfolio/create-portfolio-page.md) will be used to present your projects. You don't need to add any content to that page.

To control how to portfolio display, you can navigate to **Appearance > Customize > Portfolio > Portfolio Page** section. All options insdie this section are described in [Theme Options > Portfolio > Portfolio Page](theme-options/portfolio.md?id=portfolio-page)


### Portfolio Layouts

Konte supports 2 differnt layouts for the portfolio page. You can select the portflio layout in **Appearance > Customize > Portfolio > Portfolio Page**.

- **Grid** - [Demo of Portfolio Grid](https://konte.uix.store/furniture/portfolio/?header_version=v1)
- **Masonry** - [Demo of Portfolio Masonry](https://konte.uix.store/portfolio/)


### Portfolio Columns

At this moment, Konte only supports 2 and 3 columns. You can change the number of columns on portfolio page in **Appearance > Customize > Portfolio > Portfolio Page**.


### Number of Portfolio Items

There is an option in **Settings > Reading** that let you specify how many project will be show up per page. It is **Portfolio items show at most** option.


### Floating Icons on Portfolio Page

By default, Konte has the scroll down icon and social icons sticky on the portoflio page. If you don't like them, you can turn them off in **Appearance > Customize > Portfolio > Portfolio Page**.

Social icons are the **Social Menu** which can be edited in **Appearance > Menus**.
