# Portfolio Project Page

Konte support 2 layouts for portfolio page. You can the layout for your project page in **Appearance > Customize > Portfoliio > Project Page**.

- [Project page with layout v1](https://konte.uix.store/portfolio/natural-handbag/)
- [Project page with layout v2](https://konte.uix.store/furniture/portfolio/the-adagio-chair/?header_version=v1)

On this customizer section, you can also control project sharing chanels, related projects display or the project navigation.
