# Footer Layout

You can find all options for the footer under **Appearance > Customize > Footer** menu.


## Enable Footer Sections

With the Konte theme, you have 4 sections for the footer:

- Extra content: display custom content like HTML/shortcodes at footer. We use it to display the subscribe form on our demo site.
- Footer Widgets: display columns of widgets on footer.
- Instagram: display Instagram photos on footer.
- Footer Main: display main footer elements, such as the copyright information, footer menu, social icons, currency switchers, etc.

You can enable/disable/re-order them in **Customize > Footer > Footer Layout**. You can also change the container width of the footer in this settings panel.


## Footer Background

You can change the footer background in **Customize > Footer > Footer Background**. You can also set different footer background for blog and shop pages.

> [!NOTE] This option can be overidden in the **Display Settings** box in every single page.
