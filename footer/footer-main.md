# Footer Main

Footer main is the main section of the footer. This section may contains the copyright information, footer menu, social icons, currency and language switchers, etc. All settings for footer main can be found in **Customize > Footer > Footer Main**.


## Add Items to Footer Main

![Footer main builder](_images/footer--main-builder.png#alignright)

Like the header builder, you can add items to footer main in **Customize > Footer > Footer Main**. Footer main contains 3 columns. Simply click the button **Add Item** to add a new item to a footer column. After that, you can select what item you wish to add to the footer main from the dropdown menu.

You can also re-order items by dragging them in the order you want. At this moment, Konte supports following items:

- **Copyright**
- **Footer menu**
- **Social menu**
- **Currency Switcher** (requires WOOCS plugin installed
- **Language Switcher** (requires WPML plugin installed
- **Currency and Language Switchers** (requires WOOCS & WPML plugins installed
- **Custom text**


## Footer Items Direction

By default, Konte displays footer items in vertical direction. You can change it in **Customize > Footer > Footer Main**.


## Edit Copyright

You can edit the copyright information in **Customize > Footer > Footer Main**. There is an option **Footer Copyright** that allows you to edit it. This is the default value.

`©2019 Konte. All rights reserved`


## Footer Menu

In order to setup this menu, please go to **Appearance > Menus** and assign a menu for **Footer Menu** location.

![Footer menu](_images/footer--menu.png)


## Footer Social Icons


We use a normal menu for social icons on the right side of footer. It is pretty simple to create your own social menu icons there. You just need to create a new menu (or edit your current menu) and add link to your social pages. Remember to assign it to **Footer Social** menu location. This menu will detect the correct icon from the URL. For example, if the URL contains "twitter.com" it will display the Twitter icon.
