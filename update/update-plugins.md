# Update installed plugins

Every time we update the Konte theme, we will include the latest version for included plugins. If after updating the theme, you see an update message in the admin dashboard, please follow this guide to update them.

- **Step 1** - Navigate to **Appearance > Install Plugins** to view the list of updated plugins.

- **Step 2** - If you translated plugins and the language files are in **plugins/your-plugin-name/languages/** (For example, _plugins/Konte-addons/languages_), you need to upload them to **wp-content/languages/plugins/**. If not, after updating plugins, your translated language files will be lost.

- **Step 3** -  Click to update link after each plugin. All your content such as pages, options, images, and posts will not be lost or erased by doing this. However, any customizations to the plugin’s core files, such as PHP files will be lost.
