# Page

This section contains options to control the display of the single page. At the current version of Konte, you are able to select the page header type and set the page header height.

- **Page Title Display** - If a page has thumbnail image, you can select to display the page title above or in front of that page thumbnail image.
- **Page Header Height** - set the height of page header image. You can also select the full screen page header.

> [!NOTE] Please note there are default values only. In each page, you can overwrite these settings and make different pages has different page headers.
