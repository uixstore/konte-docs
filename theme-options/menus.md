# Menus

![Cusomize Menus](_images/customize-menus.png#alignright)

This is a default panel of WordPress. This panel is used for managing navigation menus for content you have already published on your site. You can create menus and add items for existing content such as pages, posts, categories, tags, formats, or custom links.

Menus can be displayed in [locations](header/menus.md) defined the Konte theme or in widget areas by adding a "Custom Menu" widget.

You can see it is similar to the Menus screen in **Appearance > Menus**. Therefore, you can view the [Header > Menus](header/menus.md) section for more detail. Just a note, configuring mega menu is not supported in this screen. You can do it only on **Appearance > Menus** page.
