# Widgets

WordPress Widgets add content and features to your sidebars. In the Konte, you have following sidebars:

- **Blog Sidebar** - it is displayed on the blog, category, tag, post pages.
- **Shop Sidebar** - it is displayed on the shop, product category, product tag pages.
- **Footer Sidebars** - each footer sidebar is a column in the footer widgets area.
- **Off Screen Sidebar** - this sidebar is displayed if you select header hamburger icon behaviour as open this sidebar.
- **Products Filter** - this is a special sidebar. It is displayed on the shop, product category, product tag pages. But it is only show when you select a  **Products Toolbar Layout** which is supported the filtering icon.

Remeber to select a layout which has a sidebar in the [Layout](theme-options/layout.md?id=default-layout) section first if you want sidebars to be displayed.
