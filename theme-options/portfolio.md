# Portfolio

![Customize Portfolio](_images/customize-portfolio.png#alignright)

This section contains sections which have options for controlling the display of portfolio page and single project page.


## Portfolio Page

![Customize Portfolio Archive](_images/customize-portfolio--portfolio.png#alignright)

This section contains options for the portfolio pages.

- **Portfolio Layout** - select the layout of your portfolio page.

	- **Grid** - display projects in a grid layout ([Portfolio Grid Demo](https://konte.uix.store/furniture/portfolio/?header_version=v1))
	- **Masonry** - display projects in a masonry ([Portfolio Masonry Demo](https://konte.uix.store/portfolio/))

- **Columns** - select how many columns you want to display projects in.
- **Page Header** - turn on/off the page header on portfolio page.
- **Page Header Content** - select content type for page header. You can select either "Portfolio Page Content", "Portfolio Page Title" or "Custom Content". The selected content type will be used as the content of the page header on portfolio page. The portfolio page can be set in **Settings > Reading**.
- **Categories Filter** - turn on/off the filter menu on top of projects on the portfolio page. By default, it will display all categories. You can also enter what categories you want to use for the filter menu. If you select the option **Replace by sub-categories** bellow, this filter menu will be replaced by sub-categories when you are on the portfolio category page.
- **Floating Socials Icons** - display social icons fixed on the the portfolio page. These icons are the **Social Menu** which can be controlled in **Appearance > Menus**.
- **Scroll Down Arrow** - display a fixed scroll down icon on the side.
- **Navigation Type** - select navigation type. You can select either numeric navigation or load more button.

## Project Page

![Customize Portfolio Single](_images/customize-portfolio--project.png#alignright)

This section contains options for the single project page.

- **Project Layout** - select the layout for your project page.
- **Project Sharing** - enable or disable the social sharing for a single project. You can select what social channel you want to use. You can also order these icons in the order you want.
- **Single Navigation** - enable or disable the single project navigation. It is the next/previous navigation.
- **Related Projects** - enable or disable the related projects section at the bottom.
