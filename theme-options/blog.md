# Blog


![Customize Blog](_images/customize-blog.png#alignright)

This section contains options for controling the display of blog and single post pages. You can also control featured content on the blog page with the blog header section.


## Blog Header

![Customize Blog](_images/blog-header.png)


![Customize Blog](_images/customize-blog--header.png#alignright)

Blog header is a the top section on the blog page. It contains the blog title, social icons, blog menu and the blog search form.

In this section, you can see following options:

- **Enable Blog Header** - turn on/off the blog header.
- **Blog Header Display** - select what pages you want to display the blog header. By default, it is displayed on blog, single post, category and tag pages.
- **Blog Header Text** - enter the blog header title.
- **Blog Search** - turn on/off the blog search form on the blog header.
- **Social Icons** - turn on/off the social icons on the blog header. These icons are social menu which can be controlled in **Appearance > Menus**.
- **Blog Header Menu** - turn on/off the social icons on the blog header. These icons are social menu which can be controlled in **Appearance > Menus**.
- **Header Image** - turn on/off the social icons on the blog header. These icons are social menu which can be controlled in **Appearance > Menus**.
- **Header Text Color** - select text color of the blog header.


## Blog Archive

This section contains options for controling the blog layout, featured content section, blog navigation type, etc. Following is the details:

- **Featured Content** - turn on/off the featured content section the top of blog page.
- **Featured Tag** - specify the post tag to get featured posts from.
- **Number of Items** - enter the number of posts to display in the featured section.
- **Featured Content Display** - select featured content display type as carousel or slider.
- **Slider Height** - set the height of feratured content.
- **Featured Posts** - turn on/off featured posts section. It is pretty similar to the featured content section but will be displayed as a post grid.
- **Featured Posts Tag** - specify the post to get featured posts from.
- **Number of Posts** - enter the number of posts to display in this featured posts section.
- **Blog Layout** - select the blog layout.
- **Excerpt Lenght** - enter numner of words to cut off from a post to displays as the post excerpt on the blog page.
- **Navigation Type** - select the navigation type. You can choose either "Numeric" or "Load more" button.


## Blog Single

This secton contains options for controling the display of single blog page. It has following options:

- **Author Box** - turn on/off the author biography box at the end single post.
- **Post Navigation** - turn on/off the single post navigation. This is the navigation to the next/previous post.
- **Related Posts** - select to display related posts at the end of post or not.
- **Post Sharing** - turn on/off the post sharing option at the bottom of post and select what social chanels do you want to use.
