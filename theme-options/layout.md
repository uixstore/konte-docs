# Site Layout

![Cusomize Layout](_images/customize-layout.png#alignright)

The Site Layout section makes it easy for you to manage your site layout type - sidebar layouts. You can select either: no sidebar, sidebar left or sidebar right.

####Default Layout

The **Default Layout** option is used for the blog page, category, tag and other pages. It is also used for your custom content pages. For example, if you use a plugin to add custom content type (like Events), this option will be used for all event pages.


#### Post Layout

The **Post Layout** option is used for the single blog post only.

#### Shop Layout

The **Shop Layout** option is used for the shop page, product category, product tag pages. Please note that it **is not used on single product** page. The layout of single product page is fixed as no sidebar.

#### Sticky Sidebar

If you enable this option, the sidebar on your site will be sticked on top when scrolling your site.
