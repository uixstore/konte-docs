# Mobile

This panel contains sections which have options for controlling the responsive display of your site.


## Header


This section contains options for the site header on mobile.

- **Topbar** - display the topbar on mobile. By default, Konte hide the topbar on mobile. If you want to keep it on mobile, please enable this option.
- **Header Height** - set the mobile header height.
- **Mobile Custom Logo** - if you want to use a different logo on the mobile header, you can enable this option then upload your custom logo.
- **Logo Position** - select the position of your logo on mobile header. You can choose either **Center** or **Left**.
- **Header Icons** - manage mobile header icons. You can add/remove/arrange icons on your mobile header.



## Menu


This section contains options that help you design your mobile menu.

- **Mobile Menu Layout** - design your mobile menu by enable/disable mobile menu items or arrange them.
- **Search Form** - select what the mobile menu search form looking for.
