# Shop



![Customize Shop](_images/customize-shop.png#alignright)

This panel contains sections which have options that help you control the display shop, product, cart and other related parts. We will have a separated tutorial for controling the WooCommerce plugin and related plugins bellow. This panel contains following sections:

- Product
- Products Catalog
- Page Header
- Products Toolbar
- Cart
- Badges
- Quick View
- Notifications



## Product


This section contains options for controling how the single product display. You can select the product layout, toggle the lightbox or enable the product sharing, etc.

- **Product Layout** - select the product layout. At this moment, Konte support 7 different product layouts.
- **Auto Background** - with some product layouts, Konte can get image background and set it as the product page background.
- **Image Zoon** - turn on/off the product image zoon feature.
- **Image Lightbox** - turn on/off the product gallery lightbox.
- **Ajax Add To Cart** - turn on/off the ajax add to cart on sinlge product page. It is off by default.
- **Product Sharing** - turn on/off the product sharing function. If you turn it on, you will be able to select what social chanels to be used.



## Products Catalog


This section contains options for controling elements on the shop page.

- **Catalog Layout** - select layout of the products catalog pages. You can choose either from _Standard_, _Masonry_ or _Carousel Slider_.
- **Product Hover** - select product hover style. This theme support 5 styles of product on hovering: Classic, Thumbnails slider, Other Thumbnail (Fade In), Zoom and Simple.
- **Navigation Type** - select navigation type from _Numeric_, _Load more_ or _Infinite Scroll_.




## Page Heder


This section contains options for controling the products toolbar on the shop page. This is toolbar has tools that help visitors to navigate your shop page easier.

- **Page Header Style** - select page header style of the page header on the products catalog pages.
- **Page Header Container** - select the container width of the page header.




## Products Toolbar


Products Toolbar is a section on the top of the shop page, bellow the page header. It contails tools that help visitors easily navigate through your shop page like: columns switcher, products quick search, products filter, products tabs, etc. This section contains options that help you control these tools.

- **Products Toolbar** - turn on/off the products toolbar on the shop page.
- **Products Toolbar Layout** - select a layout for the products toolbar. Each layout contains different tools.
- **Columns Switcher** - select what columns do you want to support on your products catalog page.
- **Products Tabs** - select product tabs type.
- **Products Filter** - select how you want to display filter fields on the shop page.




## Cart


This section contains options that help you control the cart page display as well as shopping cart related things.

- **Open Cart Panel After Added** - automatically open the cart panel after successful addition.
- **Cart Icon** - select the cart icon for your site. You can select to use the theme's icon or upload your own icon or use SVG icon code.




## Badges


Konte supports 4 types of product badges. You can enable/disable each of them and control how it display in this section.

- **Badge Shape** - select the shape of product badges. Konte supports round and rectangle shapes.
- **Sale Badge** - turn on/off this badge for your products.
- **Sale Badge Type** - select to simply display a "Sale" text or display the sale percentage.
- **New Badge** - turn on/off the badge for new arrival products.
- **New Badge Text** - enter the text of the new badge. It is "New" by default. You can also set how many days a product set as new from the date it is published on your website.
- **Featured Badge** - turn on/off the featured badge for featured products.
- **Featured Badge Text** - enter the text of featured badge. It is "HOT" by default.
- **Sold Out Badge** - turn on/off the sold out badge for out of stock products.
- **Sold Out Badge Text** - enter the sold out badge text. It is "Sold Out" by default.

> [!TIP] Beside setting newness days, you can set a product as a new one in the **Advanced** tab when editing it.


## Quick View


This section contains options for controling the display of product quick view.

- **Quick View Style** - select the product quick view style. You can choose to display the quick view as a modal or an off screen panel.
- **Dynamic Background Color** - enable to change the quick modal background to be the same to product images.
- **Product Link** - Add a link to product single page to the into the the quick view modal/panel. If you enable this option, you will be able to set the link text too. It is "View product details" by deafult.



## Notifications


This section contains options for controling shop notifications.

- **Added to Cart Notification** - turn on/off the notification of product successful addition. If you enable this notification, you can also enter the message to be displayed.
- **Added to Wishlist Notification** - turn on/off the notification when people added a product to their wishlist successfully. If you enable this notification, you can also enter the message to be displayed.
