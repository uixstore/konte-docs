# Footer


![Customize Footer](_images/customize-footer.png#alignright)

This section contains options for controlling the site footer layout and content. You can set the footer layout, change the background, toggle footer sections, manage footer items, etc.


## Footer Layout

![Customize Footer Layout](_images/customize-footer--layout.png#alignright)

This section contains options for controlling the site footer layout, toggle footer sections and sort these sections.

- **Footer Sections** - manage footer sections. You can turn on/off them by clicking on the eye icon. You can also drag and drop to change the order of these sections.
- **Footer Container Width** - select the footer container width.



## Footer Background

![Customize Footer Background](_images/customize-footer--background.png#alignright)

This section contains options for controlling the site footer background. You can also set different backgrounds for blog or shop page.

- **Background Scheme** - select the footer background color scheme.
- **Custom Background for Blog** - select to use a different background for blog pages.
- **Custom Background for Shop** - select to use a different background for shop pages.


## Footer Extra

![Customize Footer Extra](_images/customize-footer--extra.png#alignright)

Footer Extra section was built to help you add additional information or components to the site footer. On our demo, we use it to display the subscribe form at the footer, on all pages. This section contains only one option to enter the custom content for it. It allows you to enter plain text, HTML code and shortcodes.



## Footer Widgets

![Customize Footer Widget](_images/customize-footer--widgets.png#alignright)

This Footer Widgets section allows you to display widgets at footer, in columns. It contains options that control the layout of these widgets.

- **Footer Widgets Layout** - select how many columns do you want to use to show widget on footer.
- **Flext Column Width** - enable this option to make widgets column with be flexible. It will make sure all widgets display fit perfectly to the footer container width.



## Footer Instagram

![Customize Footer Layout](_images/customize-footer--instagram.png#alignright)

This section contains options for controlling the display of Instagram feed on your site footer.

- **Number of Photos** - set number of Instagram photos you want to show on the footer.
- **Number of Columns** - select how many columns you want to show Instagram photos in.
- **Show Profile Link** - enable to show the Instagram user profile link.

> [!WARNING] Remember to set the **Instagram Access Token** in **General > API Keys** section first. Without this access toke, the Instagram feed won't show up.



## Footer Main


This is the main section of the footer. You can manage items that you want to display on this section.

- **Left Items, Center Items, Right Items** - manage footer main items. This section has 3 parts: left, center and right. You can add/remove/arrange items in each part.
- **Items Display Direction** - select the direction to display footer items. You can display them in vertical or horizontal direction.
- **Border Line** - display a border line on top of this section.
- **Footer Copyright** - enter the copyright text of the _Copyright_ item.
- **Custom Text** - enter the custom text content of the _Custom Text_ item.
