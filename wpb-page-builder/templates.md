# WPBakery Page Builder Templates

![Open WPB template library](_images/wpb-templates--open.png#alignright)

If you are going to use the WPBakery page builder and want to use a predefined layout of the theme, or you want to create multiple pages that have the same general design, one of the easiest ways is to use/create a "Template".

In the WPBakery Page Builder editor, you can open the template library by clicking on the "Templates" icon on top of the editor.



## Theme templates


![WPB default templates](_images/wpb-templates--default.png)

With the theme's predefined templates, you can recreate pages from the demo without importing the demo content again. Once you inserted a page/section template to your page, you are free to edit it to fit your requirements.

You can access and use predefined templates of the theme right in the page builder by following these steps.

1. Click the template library icon to open it.
1. Select the **Default Templates** to access the list of theme's templates.
1. Hover the  mouse on the template name, you will see the plus (+) icon to add that template to your page. You can also preview a template by clicking on the arrow icon right beside the plus icon.


## Premium Template Library

If you have a dedicated license of the WPBakery Page Builder (you have to purchased it on the CodeCanyon website), you can activate the premium template library. You can read more about it in the documentation of WPBakery Page Builder plugin.


- Video tutorial: [How to access and work with WPBakery template library](https://wpbakery.com/video-academy/work-template-library/)
- The online documentation: [WPBakery Template Library](https://wpbakery.com/features/template-library/)


> [!WARNING] The bundled version of WPBakery Page Builder doesn't require a license to work, therefore you are not able to access the premium template library. You need a regular license if you want to access it.


## Create Your Own Template

This template library is very useful if you want to create multiple pages that have the same design, or just want to create reusable layouts/sections that you have spent many time to complate. When you saved a specific page as a template, you can then re-insert it into any given page to start with the same design and then modify accordingly. You just need to open the "Template Libary" as above, then give the current design a name before saving it.

> [!TIP] You are also able to export your templates with the default Exporter tool of WordPress. Then you can import them to other website which are using the same WPBakery Page Builder. But please keep in mind the Exporter will not export default templates of the theme. You need to use the same theme to have default templates.
