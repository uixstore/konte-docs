# Header Layouts

Konte offers two methods to setup your header layout. You can choose either a pre-built header layout with fixed elements or build your own layout. Just navigate to **Appearance > Customize > Header > Header Layout** and select to use a pre-build header layout or build your own.


## Pre-build Header Layouts

Konte supports 10 pre-build header layouts. We call them as "Header V1, Header V2,... Header v10". Just select the option **Present** as **Use pre-built header** then you can .

- **Option**: Header Layout
- **Section**: Appearance > Customize > Header > Header Layout

![Header layouts](_images/header--layouts.jpg)


## Header background

At this moment, Konte support to select header background color as **White** or **Transparent** only. You can change the header's background color with the option **Header Background**.

- **Option**: Header Background
- **Section**: Appearance > Customize > Header > Header Background

> [!NOTE] The header background can be changed for each page. While editing a page, you can see a **Display Settings** meta box bellow the editor.


## Header text color

After select background color for the header, you should also select the text color. It will help your visitors easier to see the menu, icons on the header. With the help option **Header Text Color**, you can change the text color easily. But please note, this option is only avaiable when you select **Header Background** as **Transparent**. With the **White** backgroud, the text color is set as **Dark** automatically.

- **Option**: Header Text Color
- **Section**: Appearance > Customize > Header > Header Background
- **Require**: The option _Header Background_ must be _Transparent_

> [!NOTE] The header background can be changed for each page. While editing a page, you can see a **Display Settings** meta box bellow the editor.


## Header hover background

If you select **Transparent** as **Header Background**, you will be able to enable or disable the background color of the main header while hovering on it.

- **Option**: Header Hover Background
- **Section**: Appearance > Customize > Header > Header Background


## Sticky header

Konte supports 2 kinds of sticky header and also allows to disable it. By default, it is disabled. You can select either _disable_, _normal sticky_ or _smart sticky_.

- **Option**: Sticky Header
- **Section**: Appearance > Customize > Header > Header Layout
