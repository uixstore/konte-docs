# Logo

You can change the logo image, select to use text logo, adjust margin,... in **Customize > Header > Logo**. All options for are is described in the section [Theme Options > Header > Logo](/theme-options/header.md?id=logo)


## Change logo image

To change the logo image, you must ensure the option **Logo Type** must be **Image**. Then select the logo image with options **Logo** and **Logo Light**.


## Text Logo

If you want to use text logo, Konte has options helping you design your text logo easily. Please follow these steps:

1. Select **Logo Type** as **Text**.
1. Enter the text for your logo in option **Logo Text**.
1. Select the favourite font variations for your logo. You can select font family, font weight, font size, letter spacing, text transform.


## SVG Logo

Konte allows you use SVG image for your logo. There are 2 methods to use SVG logo.

1. Select **Logo Type** option as **SVG** then paste the SVG code to the textarea option bellow.
2. Replace the default Konte logo by your own. You just need to install the konte child theme and upload your svg logo image to the `images` folder. You logo image must be named as `logo.svg` and `logo-light.svg` if you have the light version of it.


## Retina logo

If you are using text logo or SVG logo, it is retina ready by default.

But if you are using image logo, there are 2 options that allow you to specify the width and height of your logo image. They are **Logo Width** & **Logo Height**. By default, you don't need to enter values for them. The logo will be display in nature dimension. But if you want the logo displays well on retina screens, you should prepare it in double dimension then enter these values as regular dimension. For example, your logo is 140x70, you should design it in 280x140. Then enter the value of width is 140px or height is 70px.

> [!TIP] You should set one value only (Width or Height). If you set both values, it make display your logo incorrectly on mobile.
