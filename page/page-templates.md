# Page Templates

Konte includes a few Page Templates that you can choose from. Each Page Template caters to user’s specific needs.

1. **Default template** – This is the default template for all pages.
1. **Large Container** - This page template displays your content in large content. Please note it is not full width.
1. **Flex Posts** - Use this template to display flex posts. We use this template to build the home v1. [View demo](https://konte.uix.store/)
1. **Splited Content** - This page template displays your a page in splited mode. A half for the page content and another for featured image (or custom content). You can check this [About Me](https://konte.uix.store/about-me/) page to view it.
