# Display Settings

In the [Theme Options](theme-options/customizer.md), we have global settings for layouts, header color, page header,... But Konte also supports customizing these things for each individual page.

When you edit a page, you’ll see this meta box below the content editor:

![Page display settings](_images/page--display-settings.png)

In this box, you will see following sections.


### Site Header

In this section, you can change the style of the site header.

- **Header Layout** - Select a different header layout for the current page than using the default layout that was set in the Customizer.
- **Header Background** - Select the header background color. By default, it will use the **Default** value which is set in the Theme Customizer.
- **Header Text Color** - Select the header text color. By default, it will use the **Default** value which is set in the Theme Customizer.


### Page Header

This section contains options for controlling the page header for this page only.

- **Page Title Display** - change the way the page title display or hide it.
- **Page Header Height** - change the height of page header.
- **Replace Featured Image** - instead of using the featured image for the page heaer, you can use other type of content, like video, map.


### Footer

- **Footer Background** - change the footer background.


### Layout

This section contains options for controlling the layout of current page. By default, the layout for this page is set in **Customize > Layout**. But if you want to use a different layout for this page only, you can setup it here:

- **Content Top Spacing** - custom the top spacing between the header and page content. It is 60px by default.
- **Content Bottom Spacing** - custom the top spacing between the footer and page content. It is 60px by default.
- **Content Area Container** - Select the content width of the current page. This is an alternative option of the page template `Large Container` with more options.
