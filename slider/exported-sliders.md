# Exported Slider {docsify-ignore-all}

Even in the [Installation](installation/import-demo.md) section, we showed you how to import the demo content with one click. But when you select a demo to import, it will import the slider of selected demo only. If you want to use the slider from another one, you need to import its' sliders manually.


## Sliders

| Home v12  | Home v12       | parallax-section-xx.zip |
| Home v14  | Home v14       | home-14.zip      |

You can found these exported files in the theme package. They are located in folder **Demo Data**. In this folder, you will see folders of all homepages, like _home-1, home-2, home-3, ..._ You just need to extract the file **sliders.zip** inside each folder to get the slider of that homepage. Besides, you can find all exported sliders in the **Sliders** directory.


## Import a slider

You can found the importing instruction in the plugin's documentation. Please follow it to import an exported slider file. [How to import a slider](https://www.sliderrevolution.com/documentation/new-module-creation#import-zip)
