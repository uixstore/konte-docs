# Social icons inside the slider

In some sliders, you will see the social icons inside them. They are a bit different with the [social menu](footer/footer-main?id=footer-social-icons) of the theme.

![Slide global layers](_images/slider--global-layers.png#alignright)

To edit these icons, you need to open the **Global Layers" slide. This is a default section of Revolution Slider. You will find the option to open it on top of your slides. It contains layers that will be displayed on top or below your Slides.

You can check this official documentation for more clarification about the Global Layers section.

- [Global Layers defination](https://www.sliderrevolution.com/definition/global-layer/)
- [Edit Global Layers](https://www.sliderrevolution.com/documentation/global-layers/)

### Edit the social icons <!-- {docsify-ignore} -->

![Social icons layer inside the slider](_images/slider--social-icon-layer.png#alignright)

You will see some global layers, including the social icons layer. It is a text layer that contains HTML of these icons. You can edit the HTML of this layer to modify, add or remove the icons.

Following is an example of the HTML that the theme uses for the social icons:

```
<span class="slider-social-menu">
	<a href="//pinterest.com" target="_blank" rel="nofollow"><i class="fa fa-pinterest-p"></i></a>
	<a href="//instagram.com" target="_blank" rel="nofollow"><i class="fa fa-instagram"></i></a>
	<a href="//facebook.com" target="_blank" rel="nofollow"><i class="fa fa-facebook"></i></a>
	<a href="//twitter.com" target="_blank" rel="nofollow"><i class="fa fa-twitter"></i></a>
</span>
```
