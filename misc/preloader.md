# Preloader

Preloader is a layer display over the site when it is loading. In this section, you will see following options.


## Enable preloader

You can enable preloader in **Appearance > Customize > General > Preloader**.


## Change the background color

In the **Appearance > Customize > General > Preloader** section, you will found an option named **Background Color**. You can pick the color and select the opacity of the background in this option.


## Customize the preloader

If you want to customize the preloader deeper, you can overwrite it in the child theme. Just copy the file **template-parts/preloader.php** to the child theme. Then you can edit it as you wish.
