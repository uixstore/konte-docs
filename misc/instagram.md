# Instagram {docsify-ignore-all}


## Manually generate the Access Token

- Step 1: You need to have a [Facebook Developer Account](https://developers.facebook.com/apps).

- Step 2: Follow [this tutorial](https://developers.facebook.com/docs/instagram-basic-display-api/getting-started) to create a new Facebook App and config the Instagram Basic Display.

- Step 3: Use the [User Token Generator](https://developers.facebook.com/docs/instagram-basic-display-api/overview#user-token-generator) tool to generate the access token.
