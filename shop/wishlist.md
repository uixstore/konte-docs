# Wishlist

Konte theme come with a private plugin - Soo Wishlist. This is a plugin that developed to work smoothly with this theme. After activated this plugin, you will new setting tab called **Wishlist** in **WooCommerce > Settings**. This tab contains options allow you to control the display of the wishlist.
