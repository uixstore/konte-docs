# Product Page

Product page is the page to present a single product information. You can controll the product page layout, style and other things in [Customize > Shop > Product](theme-options/shop.md?id=product) section.


## Adding and Managing Products

You can easily found the detail tutorial for adding and managing product in the [WooComemrce Documentation](https://docs.woocommerce.com/document/managing-products/).

If you want to create products with varition selections, you need to use **Variable Product** type. Please check this documentation for more information about variable products.

[Variable Products](https://docs.woocommerce.com/document/variable-product/)


## Change Product Layout

You can select product layout in **Customize > Shop > Product** with the option **Product Layout**. There are 7 product layouts you can choose from:

1. Layout 1 - [View example](https://konte.uix.store/product/wyoming-backpack/)
1. Layout 2 - [View example](https://konte.uix.store/product/text-printed-t-shirt/?product_layout=v2)
1. Layout 3 - [View example](https://konte.uix.store/furniture/product/form-chair/?product_layout=v3&footer_container=konte-container-fluid)
1. Layout 4 - [View example](https://konte.uix.store/product/slim-trapered-rip-jeans/?product_layout=v4)
1. Layout 5 - [View example](https://konte.uix.store/product/pinch-weekender-slip-ons/?product_layout=v5)
1. Layout 6 - [View example](https://konte.uix.store/furniture/product/cover-wood-chair/)
1. Layout 7 - [View example](https://konte.uix.store/product/the-slouch-dress/?product_layout=v7)

With **Layout 1 & Layout 3**, you can fill the product page with a background color. If you wish, you can enable the option **Auto Background** to let the theme detect the color from product image. But please keep in mind, you can always pick the color manually for each product.

With **Layout 7**, the product will display list of products on the side. You can select what products will be listed in this section.


## Product Sharing

You select disable product sharing by selecting no social in the option **Product Sharing** which is located in **Customize > Shop > Product**.


## Ajax Add To Cart

![Product ajax add to cart](_images/woocommerce--product-ajax-add.png#alignrightfull)

By default, WooCommerce only has an option to enable ajax add to cart for products on the shop page. But with Konte, you can enable ajax add to cart on single product page too. Just enable the optio n**Ajax Add To Cart** in **Customize > Shop > Product**.


## Product Badges

All settings for product badges can be found in [Customize > Shop > Badges](theme-options/shop.md?id=badges). You can change the badge shape, change the text of badges, etc.

#### The "HOT" Badge

The "HOT" badge will be displayed on featured products. You can learn to config a featured product in [this documentation](https://docs.woocommerce.com/document/managing-products/#section-20).


#### The "NEW" Badge

There are 2 ways to set a product as new.

1. **Set the number of days which be used to calculate** - You can found the option **Product Newness** in **Customize > Shop > Badges**. This option is the number of days a product is set as new, from the published date.

2. **Mark a product as new** - While editing a product, in the **Advanced** tab of **Product Data** box, you will see an option to set a product as new.
