# Size Guide

The more information you provide, the more your customers will be happy with your service, and what’s more useful than knowing exactly how a skinny dress suits you if you cannot try it on before purchasing? A detailed table with all size information is what you need to make your online shop complete and avoid misunderstandings during a sale.


## Enable Size Guide

From version 1.3.0, Konte supports the size guide. You can enable it in **WooCommerce > Settings > Products > Size Guide**.

![Enable size guide](_images/woocommerce--size-guide.png)

You can also set to display the size guide for variable products only.


## Change Size Guide Display

In the size guide setting tab **WooCommerce > Settings > Products > Size Guide**, you can select how to to display the size guide from options:

- In product tab: add a new "Size Guide" tab in product tabs.
- By clicking on a button: add a new "Size Guide" button on the product tab. With this option, you can select the postion of this button. If you select the postion "Beside the Size attribute", you must specific the size attribute slug.

> [!NOTE] If you install WPML on your website, you should translate the option **Attribute Slug** to the slug of the Size attribute in other languages.


## Add a new Size Guide

After enabled the size guide from WooCommerce settings, you will see a new menu **Products > Size Guides**. On this page, just click the **Add New** button on top to add a new size guide for your products.

In the size guide editor, you can enter the size guide name, the description, sizes table, select how to apply the size guide.


#### Add size guide tables

The most important information of a size guide is the table of sizes for your products. In the **Tables Box**, you will see a table editor. To add/remove columns and rows just use the plus/minus buttons. Fill table cells by just clicking on them and inputing the text.

![Add size guide table](_images/woocommerce--size-guide-edit-tables.png)

If you wish to add more tables, click on the plus icon on top to add more tab. In the new tab, you can add a new table. To edit a tab name, just click the pen icon, then click the check icon to confirm your change.

![Add size guide tabs](_images/woocommerce--size-guide-add-tabs.png#alignrightfull)

- **1** - Add a new tab. In each tab, you will have a new table.
- **2** - Edit the tab name.
- **3** - Confirm the change.

<br>

#### Display a size for certain categories

![Select categories for a size guide](_images/woocommerce--size-guide-select-categories.png#alignrightfull)

By default, a new size guide will be hidden and doesn't display on any product. You can select to display it on products of all categories, or just on products of select categories.

- If you select **No category**, the size guide will be hidden except you select it for a specific product manually.
- If you select **All Categories**, the size guide will be display on all products.
- If you select **Select Categories**, you must select at least a category in the list bellow.


## Change Size Guide for a product

In the product data box, you will see a new tab for Size Guide. In this tab, you can change the default size guide to another, or you can change how the size guide display on the product page.

![Change product size guide](_images/woocommerce--size-guide-product-data.png)
