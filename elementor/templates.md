# Elementor Templates

Like other popular page builder plugin, Elementor provide the Tempalte Libary and give you the ability to create pages with the same general design, or create reuseable design. If you are not family with this template library, you can check this documentation for more information of how using it.

[Elementor Template Library Documentation](https://elementor.com/help/template-library/)

Besides Elementor templates/blocks, the Konte theme has it own predefined templates based on demo pages of the theme. You can access the theme's templates in the **My Templates** tab.

At this time, the theme provides 28 predefine templates that you will get after import the Elementor demo data, or you can import them manually from the exported file we included in the theme package.
